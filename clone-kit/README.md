# Κλώνος εφαρμογής ΚΑΕΚ με κωδικό πρόσβασης

Δημοσιεύει ένα **δεύτερο αντίγραφο** της εφαρμογής (`KAEK-teeIlias.html`) σε **δική του https διεύθυνση**.
Το αντίγραφο είναι **κρυπτογραφημένο** και ζητά κωδικό. Δεν έχει **καμία σύνδεση με το SYNOLIKO-12**.
Το footer γίνεται «Σχεδιασμός - Υλοποίηση : Χρήστος Γεωργακόπουλος/2026 - Προσφορά προς τα μέλη ΤΕΕ Ηλείας».

## Πώς δουλεύει

- `build.mjs` παίρνει την εφαρμογή από το `cgeorgako/apps` και **αφαιρεί** όλα τα τμήματα που έχουν σήμανση `@SYN`
  (καρτέλα Καταχώριση, έλεγχος επικάλυψης, ανανέωση από repo, GitHub token). Αν μείνει οποιοδήποτε ίχνος
  SYNOLIKO ή GitHub-write, το build **αποτυγχάνει** και δεν δημοσιεύεται τίποτα.
- Το [StatiCrypt](https://github.com/robinmoisson/staticrypt) κρυπτογραφεί το αποτέλεσμα (AES-256). Στη σελίδα δεν υπάρχει
  αναγνώσιμο περιεχόμενο πριν την εισαγωγή κωδικού.
- Το `deploy.yml` (μπαίνει στο `.github/workflows/`) κάνει build, κρυπτογράφηση και δημοσίευση στο GitHub Pages.
- Ο κωδικός δεν υπάρχει στον κώδικα. Διαβάζεται από το **secret `PAGE_PASSWORD`**.

## Εφάπαξ εγκατάσταση

1. Φτιάξε **δημόσιο, κενό repo** (π.χ. `apps-tee`). Το δωρεάν GitHub Pages απαιτεί δημόσιο repo.
2. Βάλε σε αυτό: `build.mjs`, `README.md` και το `deploy.yml` ως `.github/workflows/deploy.yml`.
3. Settings → **Pages** → Source: **GitHub Actions**.
4. Settings → **Secrets and variables → Actions → New repository secret**: όνομα `PAGE_PASSWORD`, τιμή ο κωδικός σου
   (τουλάχιστον 12 χαρακτήρες).
5. Actions → **Build & deploy** → **Run workflow**.

Η διεύθυνση θα είναι `https://cgeorgako.github.io/<όνομα-repo>/`.

## Αλλαγή κωδικού (όποτε θέλεις)

1. Settings → Secrets and variables → Actions → `PAGE_PASSWORD` → **Update secret**.
2. Actions → **Build & deploy** → **Run workflow**.

Σε 1–2 λεπτά ισχύει ο νέος κωδικός. Ο παλιός παύει να λειτουργεί και όσοι είχαν επιλέξει «Να με θυμάσαι» θα τον ξαναζητηθούν.

## Ενημέρωση του κλώνου όταν αλλάζει η εφαρμογή

Τρέξε ξανά το workflow (Run workflow). Παίρνει πάντα την τρέχουσα έκδοση του `main` του `cgeorgako/apps`.
Στο πεδίο `source_ref` μπορείς να δώσεις άλλο branch.

## Όρια της προστασίας (σημαντικό)

- Ο κωδικός προστατεύει **μόνο αυτή τη διεύθυνση**. Η αρχική εφαρμογή στο `cgeorgako.github.io/apps/` παραμένει ανοιχτή.
- Η αποκρυπτογράφηση γίνεται στον browser. Όποιος κατεβάσει το κρυπτογραφημένο αρχείο μπορεί να δοκιμάζει κωδικούς offline.
  Γι' αυτό χρησιμοποίησε **μεγάλη φράση-κωδικό** (π.χ. 4 λέξεις) και όχι σύντομο κωδικό.
- Όποιος γνωρίζει τον κωδικό μπορεί να τον μοιραστεί. Αλλάζοντάς τον ακυρώνεις την πρόσβαση όλων.
